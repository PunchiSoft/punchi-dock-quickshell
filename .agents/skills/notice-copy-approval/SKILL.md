# Explanatory copy approval

Preserve the owner's preference for reviewing notes, warnings, explanatory
tooltips, help text, and cause/recovery messages before they become product copy.
Ordinary labels, internal logs, and engineering records are outside this workflow.

Verify actual behavior, then propose location, trigger, English source, Spanish
translation, emphasis, expected length, and omitted cases. Present the concrete
proposal and wait for explicit wording approval before writing runtime copy,
catalogs, or end-user manual notes. Silence is not approval.

Implement approved wording literally; propose later changes to tone, length,
or emphasis again. Record approval in the active change/review note and run the
chosen localization workflow afterward. Existing explicit approval remains valid.
The explicitly requested project overview is authorized engineering
documentation and does not introduce runtime copy.
