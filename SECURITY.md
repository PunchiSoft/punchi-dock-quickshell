# Security policy

Punchi Dock Quickshell is alpha software. Only the current `main` branch is
maintained; there is no stable release, long-term support branch or security
response SLA.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting:

<https://github.com/PunchiSoft/punchi-dock-quickshell/security/advisories/new>

Include the affected component and version or commit, reproduction steps,
impact, and any suggested mitigation. Remove personal paths, usernames, tokens
and private file contents from logs and screenshots.

Maintainers will acknowledge reports on a best-effort basis.
